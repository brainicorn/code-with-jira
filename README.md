## Why this exists

[Read the full story](https://www.brainicorn.com/blog/i-built-the-jira-vs-code-extension-at-atlassian-then-i-started-over)

After working on Jira integrations at Atlassian, I kept running into the same problems:

- Slow, clunky workflows
- Features that break in real-world setups
- Too much context switching

So I rebuilt it from scratch—focused on speed, reliability, and daily use.

---

## What you can do

- Browse and search issues
- Create and edit issues
- Transition workflow states
- Delete issues (yes, really)
- Link branches and commits
- Stay inside your editor

---

## Quick Start (2 minutes)

1. Install from the VS Code Marketplace
2. Open Command Palette (`Cmd/Ctrl + Shift + P`)
3. Run: `Code with Jira: Add Jira Site`
4. Authenticate and start working

---

## Core workflows

### Work items in your editor

Browse your Jira issues in a fast, familiar tree view with custom JQL queries.

![work-items-tree](https://raw.githubusercontent.com/brainicorn/code-with-jira/main/resources/screenshots/issues-tree-view.png)

---

### Full work item editing

View and edit issues with support for:

- Rich text (Atlassian Document Format)
- Status transitions
- Sub-tasks and relationships
- Custom fields

![work-item-editor](https://raw.githubusercontent.com/brainicorn/code-with-jira/main/resources/screenshots/work-item-editor.png)

---

### Start work in one step

- Create a branch
- Transition status
- Assign to yourself
- Optionally track time

All in one action.

![start-work](https://raw.githubusercontent.com/brainicorn/code-with-jira/main/resources/gifs/start-work.gif)

## Additional capabilities

### Comment tags

Track TODO, FIXME, and custom tags across your workspace and turn them into Jira issues.

### JQL editor

Write and test queries with auto-completion and instant results.

![jql-editor](https://raw.githubusercontent.com/brainicorn/code-with-jira/main/resources/screenshots/jql-editor.png)

AI features can be fully disabled if you prefer a manual workflow.
